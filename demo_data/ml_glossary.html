Machine Learning Glossary

Short definitions of terms used in the Introduction to Machine Learning course.

Terms

Feature
An individual measurable property of the data, e.g. the age of a customer.
Label
The value a supervised model is trained to predict.
Epoch
One complete pass of the training algorithm over the whole training set.
Gradient descent
An optimisation method that repeatedly moves the parameters in the direction that reduces the loss most.
Regularisation
Any technique that penalises model complexity to reduce overfitting, e.g. L2 weight decay.
Embedding
A learned dense vector representation of a discrete item such as a word.
